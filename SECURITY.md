# Security policy

## Supported versions

LlamaPilot is currently an early release. Security fixes are applied to the latest published
version; older pre-1.0 releases are not maintained as separate support branches.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository when it is available. Include:

- the affected LlamaPilot version and Windows version;
- the minimum steps needed to reproduce the issue;
- the impact and whether untrusted input is required;
- any suggested mitigation or patch.

If private reporting is unavailable, open a minimal public issue asking the maintainer for a
private contact channel. Do not publish exploit details, credentials, local paths containing
personal information, model data, or raw logs that may contain secrets.

Please allow time for triage and a coordinated fix before public disclosure. Ordinary bugs that
do not cross a security boundary can use the normal issue tracker.
